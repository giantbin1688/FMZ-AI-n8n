# AI做空策略工作流说明文档

## 概述

本工作流是一个基于n8n构建的**AI辅助做空交易系统**，运行在FMZ量化平台上。系统通过多因子评分筛选高位币种，由AI智能体进行最终决策，自动执行做空交易。

## AI提示词架构

AI智能体使用**双层提示词架构**，分为系统提示词和用户提示词：

### 提示词文件

| 文件 | 层级 | 说明 |
|-----|------|------|
| [system_prompt.md](system_prompt.md) | System Message | 固定规则、评分标准、输出格式 |
| [user_prompt.md](user_prompt.md) | User Message | 动态数据（marketData、positions） |

### 为什么拆分？

| 方案 | 优点 | 缺点 |
|-----|------|------|
| 全放用户层 | 简单，一个提示词搞定 | 每次请求token消耗大 |
| **拆分两层** | token省，规则稳定，优先级高 | 需要平台支持system prompt |

### 11. AI智能体 + OpenAI模型

- **功能**: 基于多因子评分系统进行做空决策
- **提示词文件**:
  - System: [system_prompt.md](system_prompt.md)
  - User: [user_prompt.md](user_prompt.md)

#### 决策流程

```
Input: marketData (Top 10 Gainers) + positions (Current Holdings)
                    ↓
        【STEP 1: HARD FILTERS】
        ├─ Already held? → SKIP
        └─ Funding rate < -0.1%? → SKIP (shorts overcrowded)
                    ↓
        【STEP 2: MULTI-FACTOR SCORING】
        Calculate 6 factors, max score = 10
                    ↓
        【STEP 3: ENTRY CONDITIONS】
        ├─ Score ≥ 8.0?
        └─ Drawdown from high ≤ 5%?
                    ↓
        【STEP 4: FINAL DECISION】
        ├─ Funding rate > 0%     → "开空"
        ├─ Funding rate -0.1%~0% → "谨慎开空"
        └─ Conditions not met    → NOT OUTPUT
```

#### 关键阈值

| 条件 | 阈值 | 原始值 | 动作 |
|-----|------|--------|------|
| 费率过滤 | < -0.1% | < -0.001 | 跳过，不评分 |
| 费率谨慎 | -0.1% ~ 0% | -0.001 ~ 0 | 可开仓，标记"谨慎开空" |
| 评分门槛 | ≥ 8.0分 | - | 低于不输出 |
| 回撤门槛 | ≤ 5% | ≤ 0.05 | 当日K线从最高价计算 |
| OI/MCap过热 | > 35% | > 0.35 | 优先选择 |

#### 评分系统（满分10分）

| 因子 | 权重 | 说明 |
|-----|------|------|
| OI/MCap比率 | 3.5分 | ⭐⭐⭐ 核心指标，杠杆越高越容易爆仓 |
| K线形态 | 2.8分 | ⭐⭐⭐ 技术面信号（长上影线、十字星等） |
| 持仓量 | 1.5分 | ⭐⭐ 绝对持仓量大小，流动性保障 |
| 成交量 | 1.5分 | ⭐⭐ 成交活跃度 |
| 涨幅 | 0.5分 | ⭐ 已是涨幅榜前十，区分度低 |
| 资金费率 | 0.2分 | ⭐ 已作为过滤条件 |

#### OI/MCap比率评分标准

| 范围 | 得分 | 说明 |
|------|------|------|
| > 35% | 3.5 | 杠杆过热，优先选择 |
| 30% ~ 35% | 3.2 | 杠杆极高 |
| 25% ~ 30% | 2.8 | 正常偏热 |
| 20% ~ 25% | 2.3 | 杠杆偏高 |
| 15% ~ 20% | 1.8 | 杠杆中等 |
| 10% ~ 15% | 1.2 | 杠杆一般 |
| < 10% | 0.5 | 杠杆参与度低 |

#### 决策输出

```json
{
  "summary": {
    "total": 10,
    "filtered": {
      "alreadyHeld": 2,
      "extremeNegativeFunding": 1,
      "lowScore": 4,
      "highDrawdown": 1
    },
    "qualified": 2
  },
  "results": [
    {
      "symbol": "XXX",
      "price": 1.234,
      "change24h": "45.00%",
      "drawdownFromHigh": "3.00%",
      "fundingRate": "0.15%",
      "oiMcapRatio": "32.00%",
      "score": 8.98,
      "scoreDetail": {
        "oiMcap": 3.2,
        "kline": 2.8,
        "oi": 1.2,
        "volume": 1.2,
        "change": 0.4,
        "funding": 0.18
      },
      "factorDesc": "📊OI/MCap：32%杠杆极高 | 📈K线：长上影线见顶 | 💰持仓：80M流动性好 | 📉成交：300M活跃 | 💵费率：0.15%多头拥挤",
      "decision": "开空"
    }
  ]
}
```

#### decision取值

| 决策 | 条件 |
|-----|------|
| `开空` | 评分≥8.0 且 回撤≤5% 且 费率≥0 |
| `谨慎开空` | 评分≥8.0 且 回撤≤5% 且 -0.1%≤费率<0 |
| (不输出) | 不满足上述条件 |

## 倒金字塔加仓系统

### 策略原理

倒金字塔加仓是一种**逆势加仓**策略，专门用于做空场景。当做空后价格继续上涨（浮亏扩大）时，按照预设的涨幅阈值自动加仓，通过摊低成本来提高后续回落时的盈利空间。

**为什么叫"倒金字塔"？**
- 传统金字塔：底部仓位大，越涨加仓越少
- 倒金字塔：初始仓位小，越涨加仓越多（$100 → $150 → $300）

### 加仓配置参数

| 参数 | 说明 | 默认值 |
|-----|------|--------|
| `Add1Amount` | 加仓1金额(U) | 150 |
| `Add2Amount` | 加仓2金额(U) | 300 |
| `Add1Trigger` | 加仓1触发涨幅 | 50% |
| `Add2Trigger` | 加仓2触发涨幅（相对加仓1价格） | 70% |
| `DEFAULT_LEVERAGE` | 默认杠杆 | 10x |

### 加仓触发逻辑

```
初始开空 $100 @ 入场价 $1.00
         │
         ▼
    价格上涨监控
         │
         ├─ 价格涨至 $1.50 (涨幅50%)
         │       │
         │       ▼
         │   触发加仓1: 加空 $150
         │   记录加仓1价格: $1.50
         │
         ├─ 价格涨至 $2.55 (相对$1.50涨幅70%)
         │       │
         │       ▼
         │   触发加仓2: 加空 $300
         │   加仓完成 (2/2)
         │
         └─ 等待价格回落获利
```

### 加仓计算示例

| 阶段 | 触发条件 | 加仓金额 | 累计仓位 | 平均成本 |
|-----|---------|---------|---------|---------|
| 初始开空 | AI信号触发 | $100 | $100 | $1.00 |
| 加仓1 | 价格涨50%至$1.50 | $150 | $250 | ~$1.30 |
| 加仓2 | 价格再涨70%至$2.55 | $300 | $550 | ~$1.95 |

**注意**: 加仓2的触发是相对于加仓1的价格计算，而非初始入场价。

### 状态管理

系统使用 `_G()` 持久化存储加仓状态：

| 存储Key | 说明 |
|--------|------|
| `{coin}_pyramid_addCount` | 已加仓次数 (0/1/2) |
| `{coin}_pyramid_add1Price` | 加仓1执行价格 |
| `{coin}_pyramid_entryPrice` | 初始入场价格 |

### 持仓监控表状态显示

| 状态显示 | 含义 |
|---------|------|
| `🔺 加仓1@$1.50` | 等待触发加仓1，显示触发价格 |
| `🔺 加仓2@$2.55` | 加仓1已完成，等待触发加仓2 |
| `✅ 加仓完成(2/2)` | 两次加仓均已完成 |

### 平仓清理

当持仓被平仓（手动或自动止盈止损）时，系统自动清理该币种的加仓状态：

```javascript
// 清理加仓状态
_G(`${coin}_pyramid_addCount`, null);
_G(`${coin}_pyramid_add1Price`, null);
_G(`${coin}_pyramid_entryPrice`, null);
```

### 风险提示

1. **杠杆叠加风险**: 加仓会增加总仓位，账户杠杆随之上升
2. **爆仓风险**: 如果价格持续上涨超过预期，可能触发爆仓
3. **资金占用**: 需要预留足够资金用于加仓（初始$100 + 加仓$450 = $550）
4. **仅限做空**: 当前倒金字塔加仓仅支持做空持仓，做多不触发

```

│                     倒金字塔加仓流程                              │
├─────────────────────────────────────────────────────────────────┤
```

## 核心策略逻辑

### 做空信号筛选流程

```
1. 获取24h涨幅榜前N名
         │
         ▼
2. 过滤已持仓币种
         │
         ▼
3. 过滤极端负资金费率（< -0.1%，空头过度拥挤）
         │
         ▼
4. 多因子评分（满分10分）
   ├── OI/MCap比率 (3.5分) - >35%为过热优先选择
   ├── K线形态 (2.8分)
   ├── 持仓量 (1.5分)
   ├── 成交量 (1.5分)
   ├── 涨幅 (0.5分)
   └── 资金费率 (0.2分)
         │
         ▼
5. 评分 ≥ 8.0分 且 当日K线回撤 ≤ 5%
         │
         ▼
6. 判断费率区间
   ├── 费率 > 0%     → "开空"
   └── 费率 -0.1%~0% → "谨慎开空"
```

### 核心做空逻辑

1. **高OI/MCap比率**: >35%为过热，杠杆越高，爆仓风险越大，做空胜率越高
2. **资金费率判断**:
   - 正费率：多头拥挤，正常开空
   - 轻微负费率(-0.1%~0%)：谨慎开空
   - 极端负费率(<-0.1%)：空头过度拥挤，不开仓
3. **高位回落信号**: K线出现长上影线、十字星等见顶形态
4. **回撤控制**: 只在当日K线从最高价回撤≤5%时入场，避免追空

## 风险提示

1. **做空风险**: 做空理论上亏损无限，需严格控制仓位
2. **杠杆风险**: 默认10倍杠杆，波动10%即可爆仓
3. **倒金字塔加仓风险**: 加仓会增加总仓位和账户杠杆，需预留足够资金
4. **API限制**: 频繁调用可能触发交易所限流
5. **市值数据**: 依赖CoinMarketCap API，需配置有效Key
6. **止损机制**: 当前止盈止损功能已停用，需手动监控或设置
